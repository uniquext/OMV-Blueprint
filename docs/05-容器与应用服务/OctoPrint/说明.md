# OctoPrint - 3D 打印机 Web 远程控制与切片管理服务

> 开源 3D 打印机 Web 控制与管理平台，支持串口监控、G-code 文件管理、SD 卡写入、自动调平热力图展示及远程状态告警。
>
> - **官方文档**：[OctoPrint Documentation](https://docs.octoprint.org/)
> - **Docker 仓库**：[octoprint/octoprint](https://github.com/OctoPrint/octoprint-docker)

---

## 一、 部署架构 (Deployment)

OctoPrint 采用单容器桥接部署（Bridge），通过透传宿主机 USB 串口设备与打印机主板直接通信。

### 1.1 容器架构说明

**单容器服务**：
- **octoprint**：核心控制服务，内置轻量 Web 服务器，负责提供浏览器管理界面、串口 G-code 指令收发、机身 SD 卡高速写入控制。

### 1.2 路径与设备映射逻辑

- **硬件设备透传 (Devices)**：
  - `/dev/serial/by-id/<your-printer-serial-id>`：3D 打印机主板串口转换芯片物理硬件路径（可通过宿主机 `ls /dev/serial/by-id/` 获取），映射至容器内 `/dev/ttyUSB0`。
- **Service Local (服务自产层)**：
  - `./octoprint`：挂载至容器内部 `/octoprint`，保存所有用户账号、API Key、已上传的 G-code 文件、安装的扩展插件及配置数据。
- **公共资源层 (AppData)**：
  - 本服务不依赖共享静态资源。

## 二、 快速启动 (Quick Start)

> [!IMPORTANT]
> **硬件连接与权限检查**：
> 1. 启动前，请确保 3D 打印机的 USB 数据线已连接至 NAS，且打印机处于通电开机状态。
> 2. `global.env` 中的时区 `${TZ}` 与代理 `${PROXY_HTTP}` 已正确配置，以便 OctoPrint 容器访问 GitHub 插件市场。

1. 查阅与验证配置逻辑：
   - 配置文件：[OctoPrint.yml](../../../Compose/OctoPrint/OctoPrint.yml)
2. 在 OMV Web UI 的 **Services → Compose → Files** 页面中，识别或添加 `OctoPrint.yml`。
3. 点击 **Up** 启动容器。
4. 启动完成后，在浏览器中访问 `http://<你的NAS_IP>:8085` 进入初次配置向导。

## 三、 首次登录配置 (Initial Setup)

首次访问 `http://<你的NAS_IP>:8085` 时，按以下向导顺序完成初始化：

1. **访问控制 (Access Control)**：
   - 设置 Web 管理员账号与强密码（禁止禁用访问控制）。
2. **连接默认设置 (Default Connection)**：
   - **Serial Port (串口)**：选择 `/dev/ttyUSB0`。
   - **Baudrate (波特率)**：选择 `115200`（或保持 `AUTO`）。
   - 勾选 `Auto-connect on server startup`（服务启动时自动连接打印机）。
3. **打印机型配置 (Printer Profile)**：
   - **Name**：`<你的打印机名称>`（如 `My3DPrinter`）
   - **Model**：`<你的打印机型号>`（如 `FDM-Custom`）
   - **Print bed & build volume (成型尺寸)**：
     - Form factor: `Rectangular` (矩形)
     - Origin: `Lower Left` (左下角原点)
     - Heated Bed: 勾选 (带热床)
     - Heated Chamber: 不勾选
     - Width (X): `<宽度>` mm (根据打印机实际规格填写，如 `220`)
     - Depth (Y): `<深度>` mm (根据打印机实际规格填写，如 `220`)
     - Height (Z): `<高度>` mm (根据打印机实际规格填写，如 `270`)
   - **Axes (轴移动速率)**：保持默认。
   - **Extruder (挤出机)**：
     - Nozzle Diameter (喷嘴孔径): `0.4` mm (根据实际喷嘴填写)
     - Number of Extruders: `1`
4. **服务器与插件推荐 (Server / Plugins)**：
   - 推荐在 `Settings → Plugin Manager` 中安装：
     - **Bed Visualizer**：用于生成 3D 彩色网床拓扑热力图。

## 四、 详细配置参数表 (Configuration Table)

所有环境变量声明于 `OctoPrint.yml`，且严格依赖宿主机的 `global.env` 透传。

| 选项 | 值/变量 | 修改建议 | 说明 |
| :--- | :--- | :--- | :--- |
| **基础配置** | | | |
| 容器映像 | `octoprint/octoprint:latest` | 🟢 保持默认 | 官方稳定版 Docker 镜像 |
| 端口映射 | `"8085:80"` | 🟡 按需调整 | 将容器内置侦听的 `80` (HAProxy) 暴露于宿主机 `8085` 端口 |
| 外部网络模式 | 无 (Bridge) | 🟢 保持默认 | 默认通过 Bridge 桥接通讯，避免端口冲突 |
| **设备映射 (Devices)** | | | |
| 打印机串口 | `/dev/serial/by-id/<your-printer-serial-id>:/dev/ttyUSB0` | 🔴 必须对应 | 绑定物理硬件 ID（通过 `ls /dev/serial/by-id/` 获取），防止重启后设备号漂移 |
| **环境变量 (Environment)** | | | |
| 权限 UID | `PUID` | 🟢 保持默认 | 指向 `${PUID}`（OMV `appuser` 的数值 1001） |
| PGID | `PGID` | 🟢 保持默认 | 指向 `${PGID}`（`users` 组的数值 100） |
| 时区同步 | `TZ` | 🟢 保持默认 | 指向 `${TZ}`（如 `Asia/Shanghai`），防止日志时间戳错位 |
| HTTP 代理 | `HTTP_PROXY: ${PROXY_HTTP}` | 🟡 按需调整 | 加速容器访问海外插件仓库与更新检查 |
| HTTPS 代理 | `HTTPS_PROXY: ${PROXY_HTTPS}` | 🟡 按需调整 | 加速 HTTPS 协议流量 |
| 代理排除项 | `NO_PROXY: ${NO_PROXY}` | 🟢 保持默认 | 防止内网直连流量被错误路由进代理网关 |
| 视频流服务 | `ENABLE_MJPG_STREAMER: "false"` | 🟢 保持默认 | 无 USB 摄像头时关闭推流模块以节约 CPU 资源 |
| **目录挂载 (Volumes)** | | | |
| 主机时间挂载 | `${LOCALTIME_PATH}` | 🟢 保持默认 | `/etc/localtime` 确保日志的时间属性严格一致 |
| 核心数据存储 | `./octoprint` | 🟢 保持默认 | 映射至容器 `/octoprint` 目录，存放全部配置与切片文件 |
