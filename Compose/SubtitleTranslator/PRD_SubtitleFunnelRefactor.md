# 产品需求文档 (PRD)：字幕漏斗重构与扫描过滤机制

> **状态**：🟢 探索完成，待实施
> **版本**：v1 (2026-05-29)

## 1. 背景与目标 (Background & Objective)

在当前 SubtitleTranslator 的扫描与漏斗（Funnel）架构中，存在以下几个痛点：
1. **外置字幕时间轴不可控**：目前系统倾向于先寻找外置字幕，但外置字幕往往来源于不同压制组，极易出现时间轴不匹配的问题。而内置字幕的时间轴与视频文件 100% 绑定，更为可靠。
2. **`level` 概念的误导性**：当前使用 `level` (0, 1, 2, 3) 来标记寻找状态，数字的递增容易使用户和开发者产生“等级高低/质量优劣”的错误认知。
3. **缺乏扫描排他性控制**：对于包含原盘花絮（Extras）、特别篇（SP）或者特定下载中转目录的媒体库，目前缺乏手段将其排除在扫描范围外，导致产生无效任务。

**目标**：重构漏斗优先级判断逻辑，解耦偏好设置；引入全新的 `type` 标记体系替代 `level`；增加灵活的扫描忽略列表。

## 2. 需求范围 (Scope)

1. **忽略列表 (Ignore List)**：在扫描引擎中加入黑名单过滤机制。
2. **2×2 漏斗策略矩阵 (Funnel Strategy Matrix)**：在配置中引入位置与语言的双维度偏好设定。
3. **Type 状态机设计**：重构并细化原有的 `level`，建立 `[位置][语言]` 两位数编码规则。
4. **数据库与兼容处理**：对现有任务表的 `funnel_level` 进行重命名和数据迁移兼容。
5. **WebUI 改造**：新增黑名单交互弹窗；新增 2×2 策略矩阵配置项。

## 3. 功能详细说明 (Functional Requirements)

### 3.1 忽略列表 (Ignore List)

- **数据层**：
  - 归属于 `config.pipeline` 配置域。
  - 使用单一字符串存储，以英文逗号 `,` 分隔（例如：`Extras,SP,/downloads/seed/`）。
- **执行逻辑 (media_scanner)**：
  - 如果配置项为文件夹名称（如 `Extras`），则在目录遍历 (`os.walk`) 时，命中该名称的文件夹及其子文件夹均不作处理。
  - 如果配置项为具体文件或绝对路径子串，则命中该规则的具体文件不作处理。
- **前端 WebUI**：
  - 在“Pipeline”配置模块中，与“扫描目录”同行排列。
  - **外部表现**：一个只读的文本输入框，展示逗号分隔的字符串。
  - **交互**：点击输入框弹出一个编辑模态框（Modal）。模态框内部为一个列表，每行展示一个独立的路径/名称，支持类似 Windows 环境变量界面的【新增】、【修改】、【删除】和【调整顺序】操作。

### 3.2 2×2 漏斗策略矩阵

解耦此前的固化逻辑，增加一个全新的策略配置 TAB 页，允许用户通过两组单选互斥项决定漏斗的优先级流向：

- **组 1：位置偏好 (Location Preference)**
  - `内置字幕优先 (Internal First)`
  - `外置字幕优先 (External First)`
- **组 2：语言偏好 (Language Preference)**
  - `绝对优先 (Absolute First)`
  - `中文字幕优先 (Chinese First)`

> **说明**：两组组内互斥（只能二选一），组外必须各选其一。共产生 4 种组合。
>
> **组合场景示例**：
> 1. **内置优先 + 绝对优先**：只要内置有任何字幕（哪怕是外语），就绝不看外置字幕（即便外置有现成的中文字幕）。
> 2. **内置优先 + 中文优先**：以寻找中文/繁体为主，如果两边都有中文，选内置的；如果两边都没有中文，选用内置的外语去翻译。

### 3.3 图形字幕剥离

在对内置字幕进行判定时，如果通过 ffprobe 发现该轨道是**图形字幕**（如 `pgs`, `vobsub` 等无法提取文本的格式）：
- 视同该轨道**不存在**。
- 不触发判定，不打断漏斗流程，系统会直接继续寻找外置字幕或其他有效的文本轨道。

### 3.4 Type 定义规范

彻底移除 `level` 概念，改用 `type` 标记类型。`type` 采用两位数设计，逻辑遵循：`【位置】【语言】`。

- **位置映射 (十位)**：
  - `0` = 回填 (Backfill)
  - `1` = 内置字幕 (Embedded)
  - `2` = 外置字幕 (External)
- **语言映射 (个位)**：
  - `0` = 中文简体 (Chinese)
  - `1` = 繁体中文 (Traditional)
  - `2` = 外语字幕 (Foreign)

**完整枚举定义**：
- `01`：存在已处理的繁体转换字幕（.opencc.srt），回填跳过
- `02`：存在已处理的AI翻译字幕（.ai.srt），回填跳过
- `10`：内置字幕存在中文字幕（跳过）
- `11`：内置字幕存在繁体中文（提取 -> 转换简中）
- `12`：内置字幕存在英文/日文等（提取 -> AI 翻译）
- `20`：外置字幕存在中文字幕（跳过）
- `21`：外置字幕存在繁体中文（直接读取 -> 转换简中）
- `22`：外置字幕存在英文/日文等（直接读取 -> AI 翻译）
- `-1`：失败（包括完全找不到字幕、ffprobe 崩溃等）

## 4. 架构与数据流 (Architecture & Data Flow)

### 4.1 数据库结构变更
1. 涉及表：`subtitle_jobs`
2. 字段修改：将 `funnel_level` 变更为 `funnel_type` (INTEGER)。
3. 数据迁移策略：需要编写 SQL 迁移脚本，将旧有数据映射到新规范（或者将历史处理中非 `done`/`skipped` 的数据置回默认状态，由新漏斗重新裁决）。

### 4.2 WebUI 展示调整
1. **History 页面**：原“Funnel Level”列改为展示可读的徽章。如：`12` 显示为 `[内置|外文]`。
2. **Dashboard 统计图**：图表的分组统计按照 `1x` 和 `2x`（内置 vs 外置）或者具体的语言转化率进行展示，不再使用等级含义。
